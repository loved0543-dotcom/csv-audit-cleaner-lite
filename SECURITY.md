# Security

CSV Audit Cleaner Lite processes files locally and does not include telemetry
or a cloud upload path. Source CSV files are not overwritten by design.

For a security-sensitive report, do not attach private customer data or
credentials. Contact One Eye Automation through the product page and include
only the minimum reproduction details needed.

The app supports Windows 10/11 64-bit. Download only the complete release ZIP
and verify its SHA-256 value against `SHA256SUMS.txt`.
